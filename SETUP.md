# DIO Lab Vibe Coding - App de Finanças Pessoais com IA

## 🚀 Visão Geral

Aplicativo inovador de controle de finanças pessoais baseado em chat, utilizando IA para simplificar o registro de gastos através de conversas naturais.

## 🛠️ Setup

### Pré-requisitos

- Node.js 16+ (se aplicável)
- npm ou yarn
- Git

### Instalação

```bash
# Clonar o repositório
git clone https://github.com/marcosferreiracabral/dio-lab-vibe-coding-app-financas.git

# Navegar para o diretório
cd dio-lab-vibe-coding-app-financas

# Instalar dependências
npm install

# Executar o projeto
npm start
```

## ▶️ Como Executar

1. Instale as dependências (veja Setup)
2. Execute o comando: `npm start`
3. Acesse `http://localhost:3000`
